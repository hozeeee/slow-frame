# 水印 / 打码关键帧图层

## 已确认的选择
- 关键帧之间：默认线性插值（平滑移动），每个图层可切换为"定格"（停在上一个位置，到下一个关键帧时跳过去）。
- 首期类型：文字、emoji、图片、马赛克、纯色块（不做高斯模糊）。
- 录入方式：暂停时拖动或缩放框，就在当前时间创建或更新关键帧（自动打帧）。
- 范围：桌面端和移动端同时做。
- 图片只存在 IndexedDB 缓存里，编辑记录 JSON 不带图片；导入 JSON 后图片图层显示占位，需要重新选择图片。
- 图层可以设置出现和消失的时间。
- 时间轴上用菱形标出选中图层的关键帧，并显示它的显示时段。

## 数据模型与纯逻辑：新建 `src/overlay.ts`
- 类型定义：
  - `OverlayKind = 'text' | 'emoji' | 'image' | 'mosaic' | 'solid'`
  - `OverlayKeyframe { time, x, y, w, h }`：时间用原视频秒数，坐标用**未镜像的原视频显示像素**（和 `SpeedRange` 用同一套时间）。
  - `OverlayLayer { id, name?, kind, start, end, easing: 'linear' | 'hold', opacity, keyframes, text?, color?, outline?, imageId?, mosaicSize? }`
- 常量：最多 `MAX_OVERLAYS = 20` 个图层；最小边长 `MIN_OVERLAY_PIXELS = 8`；emoji 预设 `😀😎🙈🐱⭐❤️🔥👍`；马赛克块大小范围 4–64px，默认 16；文字最多 100 字。
- 函数：
  - `makeOverlay(kind, time, info, index)`：默认 `start = time`，`end = info.duration`，在 `time` 处放一个关键帧，框居中。默认尺寸：文字宽 40%、高 12%；emoji 为边长 15%·min(W,H) 的正方形；图片宽 25%，按图片比例算高；马赛克和色块宽 30%、高 20%。默认名称为"文字 1"、"马赛克 2"这类。
  - `resolveBox(layer, time)`：time 不在 `[start, end)` 内时返回 null。在两个关键帧之间时，按 linear 插值或 hold 取前一帧；在第一个关键帧之前或最后一个之后，取端点的值。
  - `upsertKeyframe(layer, time, box, snap)`：`|Δt| ≤ snap` 时直接改那个已有关键帧，否则插入新的，并保持按时间排序。snap 取 `1 / fps`，拿不到 fps 时用 0.02s。
  - `removeKeyframe`：至少保留 1 个；`clampBox`：框和画面至少要重叠 8px，宽高不小于 8。
  - `toDisplayBox(box, flip, W, H)`：把原视频坐标换算成镜像后的坐标。水平镜像时 `x' = W − x − w`，垂直翻转同理；同一个函数也用来反向换算。
  - `drawOverlays(ctx, frame, layers, time, opts)`：预览和导出共用的绘制函数。
    - `opts = { flip, W, H, offsetX, offsetY, scale, images: Map<id, ImageBitmap> }`。
    - 每个可见图层先换算到镜像后的坐标，减去 offset，乘以 scale。
    - text / emoji：按"完整放进框内"算字号（`measureText` 后取 min(框宽 / 文字宽, 框高 / 行高)），居中绘制；可选描边；文字本身不镜像。
    - image：`drawImage` 按 contain 方式放进框内；图片缺失时跳过（预览由编辑层显示占位）。
    - solid：用 `fillRect` 填颜色。
    - mosaic：从 `frame`（已经是镜像后坐标的画面）取框内区域，按 `ceil(w / 块大小)` 缩小画到一块复用的小 canvas 上，再关掉平滑（`imageSmoothingEnabled = false`）放大回框里。
    - 每个图层都套用 `globalAlpha = opacity`。
  - `overlayTimeMarks(layer)`：返回给时间轴用的 `{ start, end, keyframes: number[] }`。
  - `prepareImage(file)`：用 `createImageBitmap` 解码，最长边超过 1024 就缩小，输出 PNG Blob（保留透明）和 ImageBitmap。

## 持久化：`src/session.ts`
- `EditState` 新增 `overlays: OverlayLayer[]`，`defaultEdit` 给 `[]`。
- `normalizeEdit` 校验 overlays：kind 必须合法；数值必须有限；时间夹到 `[0, duration]`；`start < end`；关键帧排序去重并 clampBox；文本截断；`mosaicSize` 夹到范围内；颜色必须是 `#rrggbb` 格式；最多 20 个；缺 id 就补一个。旧记录没有这个字段时按 `[]` 处理，`version` 保持 1。
- `snapshotOf` 只在 overlays 非空时写入这个字段（写法和 flip 一样，保证旧快照还能直接比较），内容是 id 以外的全部字段，数值四舍五入后写入。
- `SessionRecord` 新增可选的 `images?: Record<string, Blob>`，只放当前图层引用到的图片。`SessionExport` / `buildExport` 不放图片。

## 编辑器状态：`src/useEditor.ts`
- 新增状态：
  - `overlays`、`selectedOverlayId`
  - `overlayImages: Record<id, { blob, bitmap }>`（同时维护一个 ref，方便 rAF 和导出读取）
- `edit` 的 memo 加入 overlays。
- 自动缓存的记录里附带被引用到的图片 Blob。恢复缓存时，用 `createImageBitmap` 重建图片。
- 导入 JSON 编辑记录时，如果图片 id 在当前缓存里找不到，就留空。
- 新增方法：
  - `addOverlay(kind, imageFile?)`：超过上限时给出提示。
  - `updateOverlay(id, patch)`、`deleteOverlay`、`moveOverlay(id, ±1)`（调整叠放顺序）
  - `setOverlayBox(id, box)`：在 `currentTime` 调用 upsertKeyframe。
  - `addKeyframeHere(id)`：用当前插值结果插入一个关键帧。
  - `deleteKeyframe(id, time)`、`jumpKeyframe(id, 'prev' | 'next')`（会 seek）
  - `setOverlayImage(id, file)`：重新选择图片。
  - `setOverlayStartEnd`
- 编辑模式互斥：选中图层时退出裁剪编辑；进入裁剪编辑时取消图层选中。
- `restoreSummary` 加上"N 个水印/打码图层"。
- 导出时把 `overlays` 和图片 bitmap 一起传给 `exportVideo`。
- 新增 `missingImageCount`，供导出面板提示"有图片缺失，这些图层不会被导出"。
- 所有新增内容都加进返回的 `Editor` 类型。

## 导出合成：`src/media.ts`
- `ExportOptions` 新增 `overlays`、`overlayImages: Map<string, ImageBitmap>` 和视频宽高 `W/H`。
- `video.process` 的处理流程：
  1. `sourceTime = sample.timestamp + trim.start`。
  2. 如果这一帧没有可见图层，走原来的 `retimeVideo`（快速路径）。
  3. 否则在一块复用的 `OffscreenCanvas` 上处理：尺寸和裁剪后的输出画面一致（即 crop 宽高，没有裁剪时就是原视频显示宽高）。
  4. `sample.draw(ctx, 0, 0)` 画出原帧，再调用 `drawOverlays`，其中 `frame` 取这块 canvas 自己（马赛克需要先把源区域复制到小 canvas 上），`offset` 取 crop 的 left/top，`scale = 1`。
  5. 返回 `new VideoSample(canvas, { timestamp: mapped, duration: mappedDuration })`，时间映射和 `retimeVideo` 一样。
- 实现时要核实：mediabunny 会不会在 process 之后自动关闭输入的 sample；把同一块 canvas 复用到下一帧是否安全（VideoFrame 从 canvas 创建时会拍快照，预期是安全的）。

## 预览渲染层
- **桌面端**：新建 `src/components/OverlayCanvas.tsx`（只负责绘制）和 `OverlayStage.tsx`（负责交互）。**移动端**：新建 `src/mobile/components/OverlayCanvas.tsx` 和 `OverlayStage.tsx`。
- OverlayCanvas：
  - 尺寸和位置跟 CropOverlay 一样，用 ResizeObserver 计算 contain 方式的画面框，canvas 盖住整个画面框，按 DPR 提高分辨率。
  - 在 rAF 循环里读 `video.currentTime`，按 `scale = 画面框宽 / W` 调用 `drawOverlays`，`offset = 0`。
  - 有马赛克可见时，先把 video 画到一块 scratch canvas 上（按 flip 镜像，分辨率同画面框）作为 frame。
  - 没有图层时不启动循环。
  - `pointer-events: none`，不随 video 的 CSS 镜像变换。
- OverlayStage（盖在 OverlayCanvas 和 CropOverlay 之上）：
  - 只在选中图层、当前时间在它的显示时段内、未播放、未裁剪编辑时，显示选中图层当前的插值框。
  - 框支持整体拖动和四角缩放：图片锁定宽高比，其他类型自由缩放。
  - 拖动过程中实时调用 `setOverlayBox`，自动打帧到当前时间；屏幕位移除以 scale 换算成像素位移，再按 flip 反向换算回原视频坐标。
  - 图片缺失时，框内显示"图片缺失，点此重新选择"。
  - 时间不在显示时段内时，舞台角落提示"当前时间不在该图层显示时段"。
  - 事件要 stopPropagation，避免触发 video 的 onClick 播放切换。
  - 移动端额外处理：pointerId 跟踪、把手热区放大。
- 图层画在裁剪框外的部分，预览里照常显示（位于裁剪框的遮罩区），导出时会被裁掉。

## 验证
- `npm run typecheck`、`npm run lint`、`npm run build`（单文件版和网站版都要构建成功）。
- 浏览器冒烟测试：用 `canvas.captureStream` + MediaRecorder 生成测试 WebM 并注入，然后：
  1. 添加色块和文字图层，在两个时间点拖动，确认生成了两个关键帧，中间时刻的位置是插值结果。
  2. 切换成定格，确认位置变为跳变。
  3. 加一个变速区间和一个裁剪框，导出。
  4. 把导出结果载入 video，seek 到对应时间，用 canvas 取色，确认色块像素出现在预期位置。
  5. 刷新后从缓存恢复，确认图片图层还在。
  6. 导出 JSON 再导入，确认图片图层显示为缺失占位。
- 如果浏览器自动化用不了，就只做静态验证，并在交付说明里写明。

## 假设与约束
- 不新增任何依赖，项目也没有单测框架，所以不新增测试文件。
- emoji 的样子取决于系统字体；预览和导出在同一台设备上是一致的。
- 打码位置只能靠手动打关键帧来跟随物体，不做自动追踪，也不做"边播放边录"。
